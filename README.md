# Junktopia — ガラクタ惑星（Web体験版）

This is the **public, playable browser demo** of Junktopia, a cozy swipe-merge puzzle about restoring a tiny scrap planet.

## Play

**https://omniaize.github.io/junktopia-web/**

> The URL becomes available once **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)** is configured and GitHub Pages deployment completes.

Use Safari or Chrome (iPhone, Android, or desktop). No local HTML download or external JavaScript is needed.

## Controls

- **Mobile:** Swipe the 5×5 board up, down, left, or right to move and merge matching junk items.
- **Desktop:** Use the arrow keys.
- Produce requested parts to restore the planet, or use the one-time dismantle tool.
- Progress is saved locally in the current browser using localStorage. Clearing browser data may reset progress.

## Scope

This repository contains only the **public demo**. The main development repository `OmniAIze/junktopia` is private. Do not copy internal game source, draft character assets, keys, or unreleased content here.

This build is a prototype, not yet an Android APK or a complete Godot release.
